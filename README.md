# RefillBridge Clinical

A modern hospital and pharmacy operations dashboard to triage, track, and resolve stuck prescription refills.

---

## 🌟 Key Features

- **Clinical Sign-In Gateway**: Secure staff login with 1-click demo profiles (Maya Rao, Dr. Patel, Elena Rostova).
- **Operations Dashboard**: Real-time shift status, workload progress, and priority refill cases.
- **Refill Queue**: Smart triage filtering by urgency, status, and blocker reason.
- **Case Workspace**: Detailed prescription timeline, root-cause diagnostics, and 1-click resolution actions (e.g. 30-day safety bridges, appointment bookings).
- **Hospital Color Palette**: Calming medical teal, clinical cyan, and clean porcelain white—designed for clinical readability.

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Build Tool**: Vite

---

## 🚀 Quick Start

### 1. Install dependencies
```bash
npm install
```

### 2. Start the development server
```bash
npm run dev
```

### 3. Build for production
```bash
npm run build
```
